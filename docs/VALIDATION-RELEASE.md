# v0.2.0 发布与回滚验收

本页记录版本标识、发布包和隔离切换验收。真实字幕与原生 ASR 的既有验收见[原生记录](VALIDATION-NATIVE.md)。

## 环境与边界

验收使用 Apple Silicon macOS / Python 3.12 的隔离虚拟环境、loopback 服务和独立 workspace。旧版对照取提交 `87e341f` 的实际构建，新版为 `v0.2.0`。Homelab 正式服务和配置保持不变。

## 隔离切换 — 2026-10-25

两个版本均从实际 wheel 离线安装 `[asr]`，各自执行 `pip check` 并核验同一份锁定模型的全部 10 个资产。虚拟环境在最终测试路径创建；切换只替换 `current` 符号链接，没有移动环境。

| 检查 | 实际结果 |
| --- | --- |
| 旧版 `0.1.0` / `87e341f` | `/api/ready=200`，读取预先建立的 v2 完成任务成功 |
| 切换候选 `0.2.0` | `/api/ready=200`；健康接口返回 `0.2.0` 和实际构建身份；旧 v2 任务可读 |
| 新版读取 v3 | 读取此前认证验收保留的 79 段平台字幕成功，没有访问平台或重新转录 |
| 旧版兼容性预检 | 旧版读取同一 v3 文件明确返回 `unsupported_material_version` |
| 故障演练 | 用缺失模型配置启动候选实例，实际 `/api/ready=503`，停止该实例后恢复旧环境 |
| 恢复数据 | 旧服务改用升级前备份的独立副本，`/api/ready=200`，旧转录可读且任务文件哈希不变 |
| 保留升级后数据 | v3 任务全部文件哈希不变，升级后 workspace 没有被备份覆盖 |
| 清理运行状态 | 本轮拥有的服务全部正常停止，loopback 端口确认关闭 |

首轮验收脚本的 25 秒启动等待预算耗尽；日志显示服务随后完成启动。保留该轮日志，将脚本等待预算调整为 60 秒后，全流程通过。服务实现和正式配置的超时未因此修改。

该演练使用未提交阶段的候选包，健康接口正确标记 `dirty=true`，不能把它当作正式发布包。正式归档要求最终提交后的干净构建，并需重新核对安装身份与归档校验。

## 自动检查与证据

Python 3.12.13 上完整测试为 **583 passed / 3 optional skips / 1 既有依赖弃用 warning**，退出码 0；启用后的发行检查 **3 passed**，退出码 0；mypy **27 source files** 无错误；wheel 与源码归档构建成功。完整测试的 3 个跳过项就是单独启用并已通过的发行检查。

本轮覆盖版本与提交溯源、未提交状态、HTTP 健康接口、归档拒绝覆盖、文件完整性、依赖清单敏感信息边界、wheel 独立安装，以及从源码归档在无 Git 环境下重建后保留身份。

原始日志、安装记录、可重复执行的演练脚本与 `rollback-smoke.json` 保留在隔离工作区的 `workspace/release-validation/`，不进入发行包。发布归档还会保存最终提交对应的版本、环境清单和构建文件校验值。

## 验收范围

这轮演练验证应用环境切换和数据恢复路径，不包含新一轮 ASR 推理、B站请求或自然凭据过期。系统级 Python / ffmpeg 回退、N100 Ubuntu 上的新发布布局与 systemd 实际切换、云 CI、正式部署仍需在对应环境验收。历史 `0.1.0` 包版本对应多个提交，演练中的 `87e341f` 仅是明确可复现的旧版对照，不能替代 Homelab 实际运行基线。
