## 接口、截图和笔记

接口与材料检查取得以下结果：

- Streamable HTTP 握手返回服务器名 `FrameNote`，发现 9 个 Model Context Protocol（MCP）工具。
- 通过 MCP 分别抽取 B站 3 张、抖音 20 张和本地片段 3 张截图。每种输入的 `get_frame` 都返回原生 `image/jpeg`，其 SHA-256 与下载文件一致。
- Skill 的标准库客户端把三份材料取回 Mac；`frames.json` 的 `relative_path` 相对笔记根目录。
- 本地片段阅读稿使用这次任务的材料生成。抖音对照稿沿用已校对的章节组织，替换为新任务与重新抽取的图片；20 张图片与原实验的哈希一致。
- 两份阅读输出共检查 67 个本地文件及章节锚点链接。抖音分章原稿按原顺序完整保留 49 段识别文本。
- 再次执行 `fetch` 后，两份阅读文档和 `corrections.md` 保持不变。

## 回归和持久化

Mac 独立环境的检查结果为：51 项测试通过，mypy 检查的 13 个运行模块通过，Skill 官方校验器通过。

规格与工程复核发现并修复两项问题：B站短链跳转丢失分 P 参数；父进程先退出后，取消操作未回收整个进程组。两项修复均补充行为测试并通过复核。

服务重启后，持久任务和截图仍可读取。旧实验的 7 个任务复制到新 workspace 后，仍可用原任务 ID 读取转录与图片；原目录保留。
